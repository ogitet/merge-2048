# Merge Tiles

同じ数字のタイルをくっつけて大きな数字を目指す、2048風のパズルゲームです。
HTMLファイル1枚だけで動き、外部ライブラリは使っていません。

**▶ 今すぐ遊ぶ: https://ogitet.github.io/merge-2048/**

## 遊び方

1. 矢印キー（またはスワイプ）で、盤面のタイルを上下左右にまとめて動かします。
2. 同じ数字のタイルがぶつかると合体し、数字が2倍になります。
3. 1手ごとに、空いているマスに新しいタイル（2 か 4）が出ます。
4. 目標の数字を作ればクリアです。動かせるタイルがなくなるとゲームオーバーです。

| 盤面 | 目標 |
|---|---|
| 4×4 | 2048 |
| 5×5 | 4096 |

クリアしたあとも「続ける」を押せば、さらに大きな数字を目指せます。

## 操作

| 操作 | キー / ボタン |
|---|---|
| タイルを動かす | 矢印キー / WASD / スワイプ |
| 1手戻す（1回まで） | Z / 「↶ 戻す」 |
| 効果音のオン/オフ | M / 🔊 |
| 盤面サイズの切り替え | 「4×4 / 5×5」（新しいゲームになります） |
| 新しいゲーム | 「New」 |

ベスト記録は盤面サイズごとに、ブラウザに保存されます。

## ローカルで動かす

リポジトリをクローンして、`index.html` をブラウザで開くだけです。ビルドやサーバーは必要ありません。

```sh
git clone https://github.com/ogitet/merge-2048.git
open merge-2048/index.html
```

効果音は Web Audio API でその場で合成しているので、音声ファイルもありません。
